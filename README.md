# LeapYear-MonthDaysCalculator
Java program that calculates the number of days in a given month of a specified year, including leap year handling using switch statements.

A simple Java program that determines the number of days in a given month of a specified year.  
It uses SWITCH statements and leap year logic to handle February correctly.

## Features
- Input year and month from the user
- Handles leap year calculation:
  - Divisible by 400 → Leap year
  - Divisible by 4 but not by 100 → Leap year
- Outputs the correct number of days for each month

## Example Usage
Enter year:
2024
Enter month:
2
Output: 29 days
